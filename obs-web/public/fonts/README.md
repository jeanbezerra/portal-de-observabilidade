# Fontes da Porto

Estas fontes são cópias locais dos arquivos WOFF2 publicados pelo site oficial da Porto e não foram modificadas.

- `open-sans-latin-variable.woff2`: família base usada no documento, nos textos e nos controles.
- `porto-roobert-variable.woff2`: família de marca usada em títulos e destaques.

Origens consultadas em 11 de setembro de 2026:

- `https://www.portoseguro.com.br/_next/static/media/cf514f5d0007dafa-s.p.1wc2mf9hp9pav.woff2`
- `https://www.portoseguro.com.br/_next/static/media/PortoRoobert_VariableFont-s.p.25omvnbr4ak6z.woff2`
