# Ícones de soluções

Os SVGs deste diretório são cópias locais dos arquivos `original` fornecidos pelo projeto [Devicon](https://github.com/devicons/devicon), distribuído sob a licença MIT. Os nomes e as marcas pertencem aos respectivos proprietários.

- `dynatrace.svg`: `icons/dynatrace/dynatrace-original.svg`
- `datadog.svg`: `icons/datadog/datadog-original.svg`
- `stackopen.svg`: `icons/opentelemetry/opentelemetry-original.svg`, usado para representar a StackOpen.

Origem consultada: CDN jsDelivr do repositório `devicons/devicon@latest`.
